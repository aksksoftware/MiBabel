# 📚 MiBabel

**MiBabel** es una aplicación de notas para Android inspirada en el concepto de *La Biblioteca de Babel* de Jorge Luis Borges. Su objetivo es ofrecer un espacio donde organizar conocimiento, ideas y material de estudio de forma sencilla, rápida y completamente local.

## ✨ Características

* 📝 Creación y edición de notas.
* 📂 Organización mediante tableros.
* 🎓 Creación de sets de tarjetas de estudio.
* 🔍 Búsqueda rápida de contenido.
* 🌙 Tema claro y oscuro.
* 📅 Calendario para navegar notas por fecha.
* 🔔 Recordatorios y eventos.
* 📄 Exportación de notas a PDF, DOCX y TXT.
* 📦 Exportación e importación de notas, tableros y tarjetas mediante archivos JSON.
* 💾 Copias de seguridad para migrar los datos entre dispositivos.
* 📱 Funciona completamente sin conexión a Internet.

## 🚀 Instalación

### Descargar el APK

Cuando exista una versión publicada, podrá descargarse desde la sección **Releases** del repositorio.

### Compilar desde el código fuente

1. Clonar el repositorio.

```bash
git clone https://github.com/TU_USUARIO/MiBabel.git
```

2. Abrir el proyecto en Android Studio.

3. Instalar las dependencias necesarias.

4. Compilar y ejecutar la aplicación en un dispositivo Android.
